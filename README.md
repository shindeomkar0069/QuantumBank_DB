# 🏦 QuantumBank DB

## 📌 Project Overview

QuantumBank DB is a Banking Management System developed using MySQL. This project demonstrates relational database design, data insertion, SQL querying, JOIN operations, and aggregate functions. It is designed as a beginner-friendly SQL portfolio project.

---

## 🎯 Project Objectives

- Design a relational banking database
- Create multiple related tables
- Insert sample banking data
- Retrieve data using SQL queries
- Perform data analysis using JOINs and Aggregate Functions

---

## 🛠️ Technologies Used

- MySQL
- MySQL Workbench
- SQL

## 🚀 How to Run

1. Open MySQL Workbench.
2. Create or open a MySQL connection.
3. Open the `QuantumBankDB.sql` file.
4. Execute the SQL script.
5. The database, tables, sample data, and queries will be created automatically.
