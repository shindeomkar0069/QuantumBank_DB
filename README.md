# 🏦 QuantumBank DB

## 📌 Project Overview

QuantumBank DB is a Banking Management System developed using MySQL. This project demonstrates relational database design, data insertion, SQL querying, JOIN operations, and aggregate functions. It is designed as a beginner-friendly SQL portfolio project.

---

## 🎯 Project Objectives

- Design a relational banking database
- Create multiple related tables
- Insert sample banking data
- Retrieve data using SQL queries
- Perform data analysis using JOINs and Aggregate Functions

## 🚀 How to Run

1. Start the **MySQL** service from the XAMPP Control Panel.
2. Open the XAMPP installation folder.
3. Navigate to:

   ```
   C:\xampp\mysql\bin
   ```

4. Open Command Prompt in this folder.
5. Log in to MySQL:

   ```bash
   mysql -u root -p
   ```

6. Enter your MySQL password (or press Enter if no password is set).
7. Execute the SQL script:

   ```sql
   SOURCE QuantumBankDB.sql;
   ```

8. The `BankingDB` database, tables, sample data, and SQL queries will be created successfully.
